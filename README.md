# VKgram

**VKgram** — альтернативный веб-клиент Telegram с интерфейсом в стиле классического ВКонтакте.
Проект создан на основе **Telegram Web K** и переделывает привычный Telegram в духе старого VK.

**Статья на моём сайте:** [defenders08.tech/vkgram](https://defenders08.tech/2026/10/09/vkgram), 
**Попробовать:** [vkgram.defenders08.tech](https://vkgram.defenders08.tech)

## Возможности

-  **Новости** — лента публикаций и историй.
-  **Сообщения** — отдельный VK-подобный интерфейс для переписок.
-  **Профили** — страницы пользователей и каналов в стиле VK.
-  **Друзья, группы и каналы** — отдельные разделы и навигация.
-  **Аудиозаписи** — музыкальная библиотека с локальными папками и сортировкой треков.
-  **Настройки VKgram** — дополнительные настройки интерфейса и приложения.
-  **Адаптивный интерфейс** для компьютеров и мобильных устройств.

## Технологии

VKgram использует основу Telegram Web K и его технологический стек:

- TypeScript
- Solid.js
- SCSS
- Vite
- MTProto / Telegram API

## Запуск

Установите зависимости:

```bash
pnpm install
```

Запустите проект в режиме разработки:

```bash
pnpm start
```

После запуска откройте адрес, который будет указан в терминале.
